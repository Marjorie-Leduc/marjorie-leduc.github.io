# Marjorie Leduc | Academic website

This is a static site with three pages. Open `index.html` in a browser to preview the whole site locally, including the portrait and PDFs.

## Publish on GitHub Pages

Create a public GitHub repository named `USERNAME.github.io`, replacing `USERNAME` with your GitHub username. Upload the **contents** of this folder to the repository's `main` branch. Keep `index.html` and the `assets`, `research`, and `teaching` folders at the repository root.

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, and save. Once deployment completes, the site will be available at `https://USERNAME.github.io/`. The files also work in a project repository served from a subdirectory.

## Edit the site

Edit `index.html` for the homepage, `research/index.html` for research and publications, and `teaching/index.html` for teaching. Replace `assets/marjorie-leduc-cv.pdf` to update the CV wherever it is linked. The shared design lives in `assets/site.css`. Committing a change to the publishing branch redeploys the site.
